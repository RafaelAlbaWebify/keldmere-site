# Keldmere Technology

Conversion-focused website for Keldmere Technology, the working commercial brand of Webify Limited.

## Purpose
Present three clearly scoped Microsoft 365 and remote IT service offers and make it easy for prospective clients to start a conversation. No proprietary software claims, fabricated testimonials, automatic prospecting, or VERIDRA dependency.

## Status
Website under design review. The legal entity remains Webify Limited pending any future company/trading name decision. Do not publish a production domain or claim Keldmere is already a registered trading name until confirmed.

## Workflow
Develop on feature branches, review in a draft pull request, and publish to GitHub Pages only after content, legal disclosures, privacy and contact details are approved.
